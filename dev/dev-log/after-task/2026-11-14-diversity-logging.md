# After Task: Action entropy and distinct genetic pairs

## 1. Goal

Finish the missing diversity metric in #164 and correct the genetic-pair
sampling defect found while reviewing Bhavya's #185 campaign.

## 2. Implemented

The logger records Shannon entropy in nats among living individuals with a
chosen action, separately for prey and predators. Code 0 is excluded, and
each entropy has its eligible individual count. With no observations the
entropy is NaN; one represented category gives zero. The calculation reads
chosen actions, including blocked movement, and draws no random numbers.

Genetic distance now samples distinct individuals for each pair. Previously
self-pairs were skipped while the denominator retained all attempted draws.
For n individuals this biased the expected value by (n - 1) / n.

## 10. Known Residuals

The genetic correction changes random draws and seeded trajectories,
because existing genetic logging shares the environment RNG. Historical
simulation caches and submitted campaign data were not regenerated by
this change. New scientific comparisons require new results with a
recorded code revision. Zero or one individual still gives genetic
diversity zero by convention, not an observed pairwise distance.
Action entropy is a population summary of last choices, not a measure
of individual repeatability or full MATLAB parity. These checks establish
implementation behavior, not biological calibration.
